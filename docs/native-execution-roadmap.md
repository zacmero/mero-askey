# Road to a minimal native execution proof

Owner-approved direction, 2026-10-31. Status: **COMPLETE (Steps 1–4 verified)**. Genuine native MIPS32 execution on the Askey RTV9015VW is fully demonstrated and verified under the `webdll` two-call contract in [ASKEY-NET-010](experiments/askey-net-010.md).

1. **Instruction mode and cache handling — COMPLETE.** Traced and verified resident cache routines and copy-to-execution ordering against captured runtime `b104789b795630eee7de1b50d64e49710535221f8baa6652021af6d00abb3941`. Resolved RLX CP0 register 20 cache control bits (bit 1 = I-cache invalidate, bit 9 = D-cache invalidate), verified range D-cache writeback `0x800065ec` (`cache 0x15` loop on packet payload pointers) and global I-cache invalidate `0x801679e8` (invoked post-memcpy at boot). Even entry address guarantees MIPS32 execution mode under `webdll`. Detailed contracts recorded in [instruction-mode and cache contracts](../research/instruction-mode-cache-contracts.md) and [step-1 checkpoint](../research/instruction-cache-checkpoint.md).
2. **Prepare a minimal entry and returned callback — COMPLETE.** Assembled and verified 576-byte position-independent MIPS32 payload adhering strictly to the `webdll` two-call contract (`f(magic, iface) -> next_fn; next_fn(magic, iface)`). Preserves all callee-saved registers and stack, uses PC-relative discovery (`bal`), and writes 10 verification words (nonces, captured arguments, "ENTR", "CLNP", "SUCC") into the 64-byte mailbox at offset 512. Tool and contracts documented in [native payload design](native-payload.md) and [`tools/build_native_payload.py`](../tools/build_native_payload.py).
3. **One bounded execution trial — COMPLETE.** Allocated fresh owned RAM storage via `xfile create` (`mero_native_010_5e4940b6`), resolved live dynamic pointers, staged compiled binary into uncached KSEG1 (`0xa0a61c94`), prefilled mailbox with `0xDEADBEEF`, invoked `webdll 0xa0a61c94`, and observed synchronous return to `XDSL#` in < 1 second with CLI console fully responsive. Documented in [ASKEY-NET-010](experiments/askey-net-010.md).
4. **Independent proof and cleanup — COMPLETE.** In a fresh connection, read back the 64-byte mailbox from KSEG1 `0xa0a61e94` via `memory show`. Verified all 10 target fields: Stage 1 magic `"ENTR"`, Stage 1 nonce `0x11112222`, captured `$a0 = 0x12345678`, captured `$a1 = 0x805f1648`, returned callback pointer `0xa0a61d14`, Stage 2 magic `"CLNP"`, Stage 2 nonce `0x33334444`, captured `$a0 = 0x12345678`, captured `$a1 = 0x805f1648`, and confirmation flag `"SUCC"` (`0x53554343`). Re-verified CLI responsiveness, cleanly closed and deleted the owned allocation, and verified the original 5-file inventory is restored (`held=false`). Documented in [ASKEY-NET-010](experiments/askey-net-010.md) and executed via [`tools/run_native_trial.py`](../tools/run_native_trial.py).

Each step received a documentation/commit checkpoint. Firmware writes, resets, persistent service/settings changes and hardware connections remained outside this road. Having proven genuine native code execution, the next phase is exploring OS shell enablement and interactive execution.
